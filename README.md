# 💫 About Me:
👋 Computer Science student at Universitas Brawijaya who enjoys building things from behind the scenes — a backend developer who believes a good application isn't just about working, but working securely. Beyond coding, I'm also fairly obsessed with cybersecurity — it's taught me to think not just "how do I make this feature work", but also "how do I make this feature hard to break".<br>
I'm currently working on building several backend systems with Spring Boot, Go, and Laravel. I'm currently deepening my skills in Go and focusing on building the right backend architecture — feel free to ask me about Java, Spring Boot, Express.js, Laravel, database design (MySQL), backend architecture, or just chat about cybersecurity.
